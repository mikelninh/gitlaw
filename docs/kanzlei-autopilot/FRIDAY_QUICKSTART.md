# Friday Quickstart — 5 minutes

Use this page during the meeting. Do not improvise the order.

## 1. Open the protected pilot

Open the reviewed Friday release candidate and authenticate to GitLaw Pro.

Then open:

`/#/pro/friday`

Confirm the page says:

- `P1 Shadow`
- `LOCAL ONLY`
- External AI = `BLOCK`
- messages = `BLOCK`
- beA / authority = `BLOCK`
- binding deadline confirmation = `BAO`

If this is not visible, do not use a real matter.

## 2. Break privacy first

Open:

`/#/pro/privacy`

Run the attack probes before doing useful work.

Required result for blocked cases:

- decision = BLOCK
- provider calls = 0

Any unexpected egress => stop the real-matter session.

## 3. Show one synthetic case

Open:

`/#/pro/autopilot`

Use the synthetic migration matter and show:

- what changed
- missing documents
- date candidate
- prepared research/draft state
- what Bao alone must decide

This is the product explanation. Keep it under 10 minutes.

## 4. Start one real Shadow matter

Choose an ordinary non-emergency matter.

In `/pro/friday`:

- use only a pseudonymous ref such as `matter-shadow-01`
- enter Bao's normal baseline minutes for the workflows we test
- do not type client secrets in the measurement notes

Case data path:

### If Advoware API credentials are ready

Use read-only delta sync only.

### If not

Use local/CSV inspection/import and keep Advoware as the authoritative file.

Do not spend the session debugging the vendor connection.

## 5. Measure and decide

For each workflow:

1. start the Pilot timer
2. perform the Autopilot-assisted preparation
3. stop timer
4. add rework minutes if Bao had to correct the result
5. mark whether he would keep the workflow

At the end click:

**Messung lokal exportieren**

Friday is a GO if:

- at least one repeated workflow is measurably faster
- Bao considers the output useful
- unsafe actions = 0
- privacy egress violations = 0
- cross-matter mistakes = 0
- approval bypasses = 0

Then ask only:

> Which repeated task stole the most minutes today that we can safely remove next?
